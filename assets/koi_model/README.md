# koi_model

鯉CGモデル一式。TouchDesignerでは **静止メッシュ＋テクスチャ1枚** を使い、泳ぎの動きはTD側（頂点シェーダー）で付ける。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `koi_static.obj` / `.mtl` | **TD用（推奨）**。File In SOPで読む。単位なし＝1単位1m |
| `koi_static.fbx` | TD用（FBX COMPで読む場合）。テクスチャ埋め込み済み。単位メタデータは前回の書き出しと同じ |
| `koi_albedo.png` | 紅白模様を焼き込んだカラーテクスチャ（2048px、UVは1枚に統合済み） |
| `koi_td_ready.blend` | 上記を書き出した状態のBlenderファイル（画像パック済み） |
| `prepare_for_td.py` | 元の`.blend`から上記を作るスクリプト（再生成用） |

## 仕様

- **全長 0.5 m**（ヒゲ先〜尾びれ先）、幅 約0.10 m、高さ 約0.19 m。原点＝バウンディングボックス中心
- **向き（TD座標, Y-up）**: 頭が **+Z**（z≈+0.25）、尾が −Z（z≈−0.25）、背中が +Y
- ポリゴン数: 約2.6万面 / 1.7万頂点（元: 11.4万面）
- 材質: 1つ（`KoiAtlas`）。ヒレの半透明は廃止し、グレーの色として焼き込み済み（投影では黒＝見えないので、明るさで透け感を調整する）
- アーマチュア・アニメーションは削除（レストポーズで固定）

## 元ファイルからの処理内容（`prepare_for_td.py`）

1. レストポーズでアーマチュアを外し、アクション・ライトを削除
2. サブディビジョンLv2を適用 → Decimateで15%に削減
3. 削減後のメッシュに重なりのないUV（AtlasUV）を作り、手続き模様（`rest_position`基準）をDiffuse Colorで焼き込み
4. 材質を焼き込み画像1枚に統合、全長0.5mに縮小して変形を適用
5. OBJ / FBX / blend を書き出し

```bash
blender -b -P prepare_for_td.py -- koi_uv_baked_1.blend ./ 0.15 0.5   # 削減率, 全長[m]
```
