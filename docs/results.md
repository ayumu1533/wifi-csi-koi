### 評価が甘く出る理由

- **同じゾーンに立ち直すだけで、隣のゾーンに移ったのと同じくらい電波が変わる。** 記録ごとの特徴量の平均（標準化した値）の距離を比べた。

  | | 扇形（3日目） | 4つ角（2日目） |
  | - | - | - |
  | 同じゾーン・別の時の記録どうし | 17.4 | 16.5 |
  | 隣り合う時間の別のゾーンどうし | 20.1 | 16.9 |
  | 1回の記録の中のばらつき | 9.2 | 11.4 |

  周単位の評価では、テストする記録に似た記録が学習側にたまたまあれば当たり、なければ丸ごと外れる。扇形のゾーン1が 1.00 なのは、ゾーン1の6回の記録が、たまたま互いに似ていたためと考えられる。リアルタイムではゾーン1に立っても反応しなかった。
- 時間によるずれもあるが、主な原因ではない。empty の記録を最初の回と比べると、ずれは 0.30〜0.50 で、おおむね後の周ほど大きい（1回の記録の中の差は 0.11）。ただし同じゾーンの記録どうしの差は、時間が離れてもほとんど増えない（扇形: 記録3回以内の間隔 16.8、4〜15回 17.1、16回以上 17.6）。位置を見ずに「何周目か」を当てると 0.29 で、でたらめ（0.17）より少し高いだけ（4つ角は 0.23 と 0.13）。
- 前の周だけで学習して後の周を当てると（学習1〜3周 → テスト4〜6周）0.671 で、周単位の評価（0.731）より低い。
- 収集のときは、ゾーンの中心付近にいて、移動中は記録していない。リアルタイムでは移動中も判定する。

### わかったこと・決めたこと

- **配置はまだ決められない。** 周単位の評価では扇形が低いが、差は小さく、条件（周の数・姿勢）もそろっていない。
- **周単位の評価は、実際に使ったときの当たり方を表していない。** 今の特徴量では、ゾーンの違いが立つたびの違いに埋もれている。リアルタイム推定では empty が一度も出ず、ゾーン1にも反応しなかった。2日目（4つ角）も、10/11のリアルタイム推定で確率がばらけていた（`touchdesigner/README.md`）。扇形だけの問題ではない。
- 配置を比べるより先に、正解付きのテスト用データ（`training.score`）で実際の当たり方を測る。そのうえで、ゾーンの数・大きさ（例: 9ゾーンをやめて「いる/いない」や左右だけにする）や特徴量を見直す。
- 扇形で使うなら `data/models/d3/et.pkl`。ただし、上のとおり当たり方は評価より悪い。

### 同日の修正

### 日をまたぐとほぼ当たらない（最も重要）

片方の日で学習し、もう片方の日を当てたときの結果（ExtraTrees）:

| TX | 1日目と2日目の基準の相関 | 差（正規化振幅の平均） |
| -- | ------------------------ | ---------------------- |
| TX1 | −0.256 | 0.455 |
| TX2 | 0.527 | 0.556 |
| TX3 | 0.479 | 0.281 |

日の中のずれ（10/03の記録で0.05〜0.11）よりずっと大きい。数cmの位置・向き・高さの違い、または部屋の中の物の配置で、CSIの形は大きく変わる。1日目のあとに機材を片付けて置き直したのなら、それが原因と考えるのが自然。

### わかったこと・決めたこと

- **今の4つ角の配置で使うモデルは `data/models/d2/et.pkl`**（2日目だけ・ExtraTrees）。両日のモデルより良く、1日目のデータは今の設置に役立たない。

- 扇形との比較は、それぞれの日の中の評価（周単位）どうしで比べる。日をまたいだ評価では比べられない。

### わかったこと

- **座った姿勢が苦手**: 座った周（2, 4）は 0.42〜0.49、立った周は 0.67〜0.72。座った姿勢は学習データに2周分しかなく、しかも評価では毎回そのうち1周が抜けるため。本番が座位なら座位の周を増やすのが最優先。
- **離れたゾーンどうしの取り違え**: 4→6（163）・4→9（166）・2→6（196）・6→2（163）・5→6（223）など、隣接していないゾーンへの誤りも多い。原因は未調査。
- **empty は 0.884**: 誤りの大半（181件）はゾーン3（手前の右、TX1寄り）と推定したもの。
- **kNN は全体で RandomForest より低い**（周3だけは同程度）。引き続き RandomForest を使う。
- 参考: 2台構成（2026-10-03、`data/d0_2tx_20261003/`）では窓特徴量で 0.887 だったが、ゾーン構成・周の数・評価条件が違うため直接は比べられない。
